Match threshold τ (0–1): how closely the live audio must match the target's opening seconds (the head) before the target is cut. Higher means fewer false cuts, but a target that sounds slightly different on air may be missed; lower catches more, but risks cutting something else. 0.60 is a reasonable start; streamjanitor calibrate suggests a value from a whole episode.
The target audio must start exactly where the target starts (±0.1 s): the cut ends at start + duration. A replacement longer than the target is shortened and faded out.
